# Documentation

Mermaid, which GitHub and most Markdown editors render.

| [database-schema.md](database-schema.md) | Developers | **ERD** and every table, column, key, constraint and index (generated from the models) |

Regenerate the schema and API reference after changing models or endpoints:

```bash
cd backend && python -m scripts.generate_docs
```

All data shown in the documentation and screenshots is **synthetic demonstration data**.
