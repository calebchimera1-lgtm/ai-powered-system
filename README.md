# AI-Driven Smart Inventory Management and Automated Receipt Digitization System

An inventory platform for supermarkets: inventory, POS, procurement, AI receipt/invoice digitization (OpenCV + OCR), demand forecasting, anomaly detection and financial analytics in KES.

**Stack:** React + TypeScript + Tailwind + Recharts · FastAPI + SQLAlchemy + Alembic · PostgreSQL · OpenCV + Tesseract/PaddleOCR · scikit-learn / statsmodels · Docker Compose

## Status

Planning stage. See [docs/00-system-design-plan.md](docs/00-system-design-plan.md) for the architecture, folder structure, ERD, AI/OCR strategy, timeline and prerequisites. Phase 1 starts after approval.
